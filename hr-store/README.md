# سنعها: متجر أدوات الموارد البشرية

متجر رقمي يبيع نماذج Excel ذكية بالعربي لأصحاب المنشآت ومنسقي الموارد البشرية في السعودية.
التسويق يكون بمحتوى ريلز بشخصية كرتونية وصوت أبو فواز، ويتولّد بالكود من `video-lab/`.

## المنتجات

| # | المنتج | الحالة | الملف |
|---|---|---|---|
| 1 | حاسبة مكافأة نهاية الخدمة (موظف واحد + كشف حتى 50 موظف) | ✅ جاهز | `products/حاسبة-نهاية-الخدمة.xlsx` |
| 2 | كشف الرواتب الشهري | ⏳ | |
| 3 | متابعة الإقامات والتأمينات مع تنبيه قبل انتهاء الوثائق | ⏳ | |
| 4 | سجل الحضور والانصراف والإجازات | ⏳ | |
| ★ | حزمة "الموارد البشرية لمنشأتك" (كل ما سبق) | ⏳ | |

إعادة بناء أي منتج: `python3 build/<script>.py`

## خطة أول شهر

| الأسبوع | المهمة |
|---|---|
| 1 | المنتجات 1 إلى 3 · اختيار الاسم والهوية والشخصية |
| 2 | المتجر على سلة أو زد · صفحات المنتجات وصورها |
| 3 | قالب الريلز (الشخصية والصوت) · تجهيز 10 ريلز قبل الإطلاق |
| 4 | الإطلاق · ريل يومي · قياس المبيعات وتحسين المنتج الأكثر طلباً |

## قبل البيع
- وثيقة العمل الحر (منصة العمل الحر) أو سجل تجاري.
- مراجعة سياسة جهة العمل عن العمل الجانبي.
- المحتوى عام، بدون ذكر أي جهة عمل ولا بياناتها.

## الهوية
- الاسم: **سنعها**، والشعار الكلامي: "سنّعها"
- الألوان: نيلي `#2B2D6E` · زعفراني `#F4A62A` · كريمي `#FFF8EC` · نعناعي `#2FB58E` · حبري `#1A1B3A`
- الشعار: `brand/` (أفقي ومكدّس، للخلفيات الفاتحة والداكنة، والعلامة لحالها). إعادة البناء: `video-lab/.venv/bin/python build/brand.py`
- الشخصية: شاب سعودي بثوب وشماغ، اسمه يتحدد لاحقاً
  - الرسم: `video-lab/src/characters/Saudi.tsx`
  - التحريك والكلام: `video-lab/src/characters/TalkingSaudi.tsx` (الفم يتبع ملف الصوت)
  - مثال: `video-lab/src/CharacterTest.tsx`
